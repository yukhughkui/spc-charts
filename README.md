# SPC 控制图工具

在线使用：**https://yukhughkui.github.io/spc-charts/**

## 为什么做这个

在完成《统计过程控制》课程作业时，需要绘制各种控制图。市面上的 SPC 软件大多需要下载安装、注册账号，用一次就吃灰，很不方便，于是写了这个网页工具——**打开链接就能用，不需要下载、注册任何软件**，数据贴进去立刻出图。

工具为单文件网页应用（38KB），所有计算均在浏览器本地完成，不上传任何数据。

## 支持的控制图

| 计量值控制图 | 计数值控制图 |
|---|---|
| 均值-标准差控制图（x̄-s） | 不合格品率控制图（p） |
| 均值-极差控制图（x̄-R） | 不合格品数控制图（np） |
| 中位数-极差控制图（Me-R） | 单位缺陷数控制图（u） |
| 单值-移动极差控制图（I-MR） | 缺陷数控制图（c） |

## 功能

- 输入数据（支持空格 / Tab / 逗号分隔，可直接从 Excel 复制），自动计算控制限并绘图
- 违规点自动标红，按 8 条判异规则自动检查，给出"受控 / 未受控"结论
- 展示所用公式与系数（A_S、B_U、B_L、d2 等，n = 2~25），可对照教材系数表
- 控制图系数表与课程课件（表 2-1、表 3-2、表 3-4）保持一致

## 使用说明

1. 选择控制图类型（可先点"载入示例"看看数据格式）
2. 粘贴数据：计量值图每行一批；计数值图每行"数量 [样本量]"
3. 点击"计算并绘图"

## 说明

开发本工具的直接目的是完成课程作业，**实际作业中只用到了 x̄-s 图和 np 图**，其余六种图类型实现了计算与绘图逻辑，但未在实际作业数据中验证过，如有问题欢迎指出。

## 技术栈

纯 HTML + CSS + JavaScript，Canvas 手绘图表，零依赖、零框架、离线可用。
